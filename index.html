    Install checklist & tools

    Often-forgotten items

    • Heat shrink tubing (assorted sizes)
    • Wire ferrules — for stranded wire into screw terminals
    • JST SM 3-pin connectors (1-wire) or 4-pin (SPI)
    • Self-amalgamating tape for outdoor waterproofing
    • Cable ties + label maker / wire labels
    • Spare fuses (one of each value used)
    • DC barrel jacks or screw terminal blocks
    • Silicone glue / butyl for IP67 strip end caps

    Tools

    • Wire stripper + ferrule crimper
    • Soldering iron + lead-free solder + flux
    • Heat gun (or lighter for small heat shrink)
    • Multimeter (V, A, continuity)
    • Small flat screwdriver for terminal blocks
    • USB-A → ESP32 cable for WLED firmware flashing
    • Phone tripod / ladder for matrix install photos

    Best practices

    • Bench-test every strip before final install
    • Label both ends of every cable
    • Photograph the wiring before closing enclosures
    • Verify polarity (red = +, black = −) twice before power on
    • Strain-relief at every connector — pull on cables, not solder joints
    • Power-on with no animation first, then add effects
    • Run the WLED Settings > LED Preferences > Brightness limit to your PSU's amp rating
    • For long data runs, add a 330–470 Ω series resistor at the strip end

    Safety & gotchas

    • Double-check chip voltage (5V vs 12V) before connecting power — wrong voltage destroys strips instantly
    • Fuse every PSU output, not just the AC input
    • Match wire gauge to current — undersized wire is a fire hazard
    • Earth/ground metal enclosures and PSU chassis
    • WS2815's data backup wire helps but doesn't replace good soldering
    • For permanent installs, use crimped ferrules — solder cracks under vibration
    • Keep a Wago-style spare for emergency reconnects on site
